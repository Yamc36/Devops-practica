# Choque Cultural - App Móvil

    Bienvenido al repositorio de la aplicación móvil para el restaurante Choque Cultural. 

## Instrucciones de Instalación

1. Descarga el código.
2. Abre el proyecto en tu editor.
3. No olvides guardar los cambios realizados.
4. Asegurate de subir el archivo a tu repositorio remoto para mantenerlo actualizado.

## Uso

Para ejecutar la aplicación localmente, puedes usar el siguiente comando en tu terminal:

    ```bash

    npm start

    ```
